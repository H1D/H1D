# Hey, I'm Artem 

Engineering software since the dial-up era. Led front-end for [Stepik](https://github.com/StepicOrg) since its founding. Led teams at [EPAM](https://github.com/epam) and [Yandex](https://github.com/yandex). Currently at [Reaktor](https://github.com/reaktor).

## Recent projects

### 🎥 Video

- [**reshoot**](https://github.com/H1D/reshoot) — Re-shoot a video from the same spot. Lays a frame of the old video over your phone camera and hides the outlines you already match. Offline-first PWA. [reshoot.artems.net](https://reshoot.artems.net)

### 💰 Financial tools

- [**dopo**](https://github.com/H1D/dopo) — Tinder for your Lunch Money transactions: swipe uncategorized ones into categories, AI-suggested (bring your own key). Zero backend — tokens never leave your browser. [dopo.artems.net](https://dopo.artems.net)
- [**easypdf-lite**](https://github.com/H1D/easypdf-lite) — Self-hostable invoice PDF generator. 10 MB Docker image, tiny runtime. [easy-invoice.artems.net](https://easy-invoice.artems.net)
- [**ics_lunchmoney_sync**](https://github.com/H1D/ics_lunchmoney_sync) — Syncs ICS Bank transactions to Lunch Money via Telegram bot + bookmarklet
- [**lunch-money-kids-companion**](https://github.com/H1D/lunch-money-kids-companion) — PWA to help kids learn healthy financial habbits. React 19, offline-first, 7 languages. [Live app →](https://lunch-money-kids.netlify.app/)
- [**ics-export-bookmarklet**](https://github.com/H1D/ics-export-bookmarklet) — Bookmarklet to export ICS Bank transactions to CSV

### 🧑‍🧑‍🧒‍🧒 Parenting tools

 - [**chore-craft**](https://github.com/H1D/chore-craft) quick chores checklist generator. [chorecraft.artems.net](https://chorecraft.artems.net/)

### 🏷️ E-commerce

- [**barcode-studio**](https://github.com/H1D/barcode-studio) — EAN-13 label-sheet generator. Print-calibrated A4 sheets, preset + custom label sizes, deterministic vector PDFs, 100% client-side. [labels.artems.net](https://labels.artems.net)

### 🖨️ 3D printing

- [**filament-booth**](https://github.com/H1D/filament-booth) — Product photos of 3D-printed parts in a browser tab. Slices the STL and path traces every bead with Blender's Cycles in WebAssembly. Has an MCP server, so a coding agent can take the photos. [booth.artems.net](https://booth.artems.net)
- [**calipr**](https://github.com/H1D/calipr) — Browser-based measurement tool using screen only. Credit-card calibration, SVG export. [calipr.artems.net](https://calipr.netlify.app/)

### 🛠️ Developer tools
